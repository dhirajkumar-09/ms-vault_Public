Official Privacy Policy & Security Charter

✓ Effective Date: October 2026 • Certified Zero-Tracking Architecture

🔒 Our Core Privacy Guarantee

MsgVault operates 100% offline. We have no external servers, no cloud databases, and no analytics trackers. Your personal messages, photos, and notification logs NEVER leave your physical Android device under any circumstance.

1. Information We Collect

None. MsgVault does not collect, transmit, store, or sell any personal information, phone numbers, email addresses, contact lists, messages, or media files to any third party or developer server.

2. How Notification Access Is Used

MsgVault requires Android's native NotificationListenerService permission solely to perform its advertised core function: archiving incoming message notifications (e.g. from WhatsApp, Telegram, Instagram, Messages) directly to your local device database so you can view unsent or deleted messages.

  • All processing occurs locally in real time on the device CPU.
  • No network packets containing notification text or media are ever created or transmitted.

3. Data Storage & Encryption Standards

All data stored by MsgVault on your device is protected by enterprise-grade cryptographic standards:

  • SQLCipher AES-256 Encryption: The entire SQLite database is encrypted using 256-bit Advanced Encryption Standard (AES) cipher.
  • Android KeyStore Hardware Isolation: Master encryption keys are generated and secured inside your phone's hardware-backed KeyStore (Secure Enclave / Trusted Execution Environment).
  • Sandboxing: MsgVault runs within its own Linux UID sandbox on Android, preventing other apps from accessing its private file directory.

4. Cloud Backups (Google Drive)

If you choose to enable the optional Google Drive backup feature, backups are stored exclusively in the private, hidden AppData folder of your own personal Google Account using standard OAuth authorization. The developer has zero access to your Google Drive or backup archives.

5. Network Permissions

MsgVault requests android.permission.INTERNET solely for the following non-sensitive background functions:

  • Checking the public GitHub repository for version updates (version.json).
  • Direct user-initiated Google Drive backup sync (if manually configured).

6. Complete Data Control & Deletion

You have absolute control over your data at all times. MsgVault provides a 1-click "Purge All Vault Data" button in Settings that instantly wipes and shreds all database records, cached media, and encryption keys from your device.

7. Independent Verification

MsgVault has been independently analyzed and certified clean by VirusTotal (0/68 Detections) across major antivirus providers including Microsoft Defender, Kaspersky, Bitdefender, and Avast. Network traffic can be independently audited anytime using tools like PCAPdroid or NetGuard.
